# 04 — Frontend–API Integration & Fallback Audit

## Summary of Contract Breakage

During Phase 2B/M3 (`fc725f8`, `f41ecf0`), client-side `try/catch` fallbacks were placed directly inside `apps/web/src/lib/public/public-api.ts` and component hooks, silently masking real HTTP errors (`400`, `404`, `409`, `422`, `500`) and synthesizing fake mutations/records.

---
